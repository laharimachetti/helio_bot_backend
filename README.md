# HELIO BOT 🤖  
### College Recommendation Chatbot

HelioBot is a conversational college recommendation chatbot that helps users explore possible colleges based on their **rank and preferred branch**.  
The project is built as a **real-world, deployed system**, focusing on backend reliability, database integration, and conversational flow.

---

## 🚀 Features
- Rank and branch-based college recommendations  
- Conversational chat flow  
- Stateful backend logic  
- MySQL-backed dataset for cutoff analysis  
- Fully deployed frontend and backend  

---

## 🛠 Tech Stack
- **Backend:** Python, FastAPI  
- **Database:** MySQL (Workbench + Railway)  
- **NLP / Chat Flow:** Dialogflow (initial version)  
- **Frontend:** HTML, CSS, JavaScript  
- **Deployment:**  
  - Backend: Railway  
  - Frontend: Netlify
